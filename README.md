# CS422-Semester-Project

A. To Launch Preview Of Website
1. Pull the current version of Main Branch into your local
2. Navigate to the folder and open 'index.html'
3. Your browser should open a tab with the website

B. For Quick Execution Of Coding/Debugging
1. Go to extensions
2. Search 'Live Server' by Ritwick Dey
3. Download and make sure it is active
4. To run, right click 'index.html' on the Explorer tab on the left, then click 'Open With Live Server'
5. A tab with 'http://127.0.0.1:5500/' should open. When you make changes and save, it should automatically update on the browser
